# 残高予測

基準残高、個別の入出金、毎月のルールから今後12ヶ月の残高を予測するアプリです。

## 公庫PDF取込

メニューの「PDFから取り込む」から、日本政策金融公庫の「お支払額明細書」を一括登録できます。PDFの解析はブラウザ内で行い、元ファイルはサーバーへ保存・送信しません。読み取った元金・利息・日付を編集し、重複確認と最終確認を経て支出予定として登録します。

引落予定日は、土日、12月31日〜1月3日、内閣府が公表する祝日・振替休日を避けて翌営業日に補正します。公表範囲外の年は予定日を明示確認してから登録します。取込履歴では明細の確認と、安全に取り消せるバッチの取り消しができます。
