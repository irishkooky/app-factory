# スタックド PR

スタックド PR は、子 PR の base を親ブランチにした並びである。

## 並び

根の PR だけが `main` を base にする。子 PR の base は親のブランチ名である。孫がいるなら、孫 PR の base は子のブランチ名である。

GitHub は、各 PR の Files changed に、その PR と base の差分だけを出す。子を開いた人は、親に既にある変更を読み直さない。

各 PR は、その時点で単体として壊れていない状態で止める。根だけが `main` に入っても、残った文書は読める。

## このリポジトリのアプリ

`AGENTS.md` は、1つのアプリの変更を1つの PR にまとめると定めている。アプリの変更はスタックにしない。共有コードとアプリの変更が同じ差分に混ざったときだけ、共有コードを別の PR に分ける。その PR の base は `main` である。

この文書は、並びを GitHub 上で見るための見本である。アプリの出荷手順には使わない。`apps/` 以外への変更なので、マージは確認のあとで行う。
